## Cloning, building, and running a simple program.
Git is one of the most commonly used programs in Linux. If a package is not in a package manager (`pacman`, `apt`, etc), then it is likely in a Git repository.  

Git is a program written by Linus Torvalds (same guy that made Linux!!) to upload updates of the kernel and keep track of updates and changes easily. Now, people
use it for all sorts of things.

### TASK
1. Go to this link to a repository and clone it using `git` (remember to use `man git` if you don't know how to use it):  
`https://github.com/GBX9570/Minifetch`  

3. Enter the directory. and using the README in the repository (either in your browser or by viewing `README.md` in the project directory), build the program.

4. Finally, run the program from the terminal to see a display of your operating system, and various details about your hardware.  

If you complete this - congrats! You just built your first program on Linux.

### What this teaches you
* The basics of git  
* The basics of building a project  
* Using a README file for instructions  
* A little bit of exposure to the terminal
