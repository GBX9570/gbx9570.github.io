# What now?
Well, that's a great question. You've got a browser, a desktop, and an app store, more or less. What more could you want? Well if that's all you want then, nothing! You're all set. But
very few people install Linux simply to mess with the browser. You now know the basics, but there's so much more to explore.  

With a C compiler, you can learn C (or if you installed GCC/clang, you can learn C++, Go, Rust, anything really) and create programs like games or little tools.  

Or maybe you wanna master bash and make command line scripts and tools (which isn't as stupid as it may seem at first glance - Neofetch was written in Bash!).  

Maybe you really really wanna learn the internals of Unix, Linux is brilliant for that - and the cool thing about Linux being open source means that anything you thing could be improved,
you can write a patch in C or rust and get it included in the kernel, and you can even use Linux code in your own projects.
