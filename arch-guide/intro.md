# Introduction to Arch Linux
I think its safe to assume you've finally decided to dip your toes into the lovechild of Richard Stallman and Linus Torvalds, and if you haven't, you're probably planning on it soon. Well this is your one stop shop for the basics of Arch Linux (and in some ways, Linux overall). In this guide, you'll get taught all the basics of Linux and how to get around.

# Why should I use Linux?
If you're asking that, you should probably go start with Linux Mint or Ubuntu. But nonetheless, brilliant question - and there's many reasons. For example, Linux is a Unix like operating system. That means that it works the same as Android, macOS, iOS, etc etc under the hood. While they might have different kernels, they all have relatively similar systems and ways of working. Unlike those operating systems, Linux has the plus that you can customise it to your hearts content. You can install another desktop environment like GNOME and make your computer look like a mac, KDE to make your computer look like windows, XFCE to make it look however you want, and a million more things for every little niche. You can make everything pink or make it all black, you can make it pretty as you want or as utilitarian as you want. Finally, Linux is very lightweight. A computer that can no longer run Windows or macOS for whatever reason (to old, too slow, whatever), Linux will likely run fine - and if one distribution runs too slow, there's a million more to choose from. There's so many reasons to choose Linux, but as with anything, there's cons too. Not all programs run on Linux. Many Windows programs will run with wine (which will be explained later on), but many also will not. Any mac exclusive apps, your shit out of luck. Also, Linux has a tendency to make people feel superior for using a different piece of software. I can assure you with certainty that you are not any better than Windows users for using Linux, and bullying a mac user is practically friendly fire.
